🌌 Nova AI --- Smart Assistant

AI • Search • Voice • Languages

Nova AI is a standalone browser-based smart assistant designed for
school, coding, math, science, writing, and research. It provides quick
built-in answers, Google Search access for live information, voice
input, spoken answers, multiple languages, and saved conversation
history.

🎤 Voice Features

Nova AI uses the browser's built-in speech capabilities. Voice
recognition uses SpeechRecognition / webkitSpeechRecognition when
supported, while spoken responses use speechSynthesis.

Voice support depends on the browser. Google Chrome is recommended.

🔎 Google Search

The Google Search button opens Google results for the question
entered by the user. This is useful for current or live information that
is not included in Nova AI's built-in responses.

💬 Built-in Assistant

Nova AI includes built-in responses for common topics such as:

Artificial intelligence

Coding

Math

Greetings

For other or current questions, the interface directs the user to Google
Search.

The selected language is saved in the browser using LocalStorage.

🕘 History

Nova AI stores recent conversations locally in the browser. Up to 50
history entries are retained. Users can open the History panel, reuse a
previous message, or clear the saved history.

▶️ How to Run

Download or clone the project.

Open index.html.

Use Google Chrome or Microsoft Edge.

Start asking Nova AI questions.

No server is required for the standalone version.

⚠️ Important Notes

Google Search opens results in a new browser tab.

Voice recognition requires browser support and may require
microphone permission.

Text-to-speech requires browser speech-synthesis support.

Conversation history is stored locally in the browser.

This is a standalone/demo assistant and is not connected to a
private AI model or backend server.
